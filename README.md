# 🍕 Pizza-ordering-app
A simple Pizza Ordering App built with Python and Tkinter. Users can enter their details, choose pizza types and sizes, add toppings, select drinks, choose the number of pizzas, and place or cancel orders through an easy graphical interface.

## Features

- Enter customer information such as name, email, phone number, and address.
- Choose from different pizza types.
- Select a pizza size.
- Add custom toppings.
- Choose a cold drink from a dropdown menu.
- Select the number of pizzas.
- Place an order through an interactive button.
- Cancel an order through a confirmation message.
- Display warnings and information using message boxes.
- Basic validation for custom toppings.

## Technologies Used

- Python
- Tkinter
- Tkinter MessageBox
- Tkinter TTK
- Object-Oriented Programming
- Basic Error Handling

## How It Works

1. Enter your personal information.
2. Select your preferred pizza type.
3. Choose a pizza size.
4. Add custom toppings if needed.
5. Select a drink from the dropdown menu.
6. Enter the number of pizzas.
7. Click **Place Order** to submit the order.
8. Use **Cancel Order** if you want to cancel.
